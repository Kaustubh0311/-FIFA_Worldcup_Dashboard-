## 📊 Project Overview

The **FIFA World Cup Analysis Dashboard** is a data visualization project developed using Microsoft Power BI. It provides insights into FIFA World Cup history through interactive charts, KPIs, and visual representations.

The dashboard focuses on analyzing tournament performance, identifying successful teams, and understanding how the competition has evolved over the years.

## 🎯 Project Objectives

- Analyze FIFA World Cup historical statistics.
- Identify the most successful World Cup-winning teams.
- Compare champions and runners-up based on goals scored.
- Explore tournament participation trends.
- Understand the distribution of World Cup victories.
- Present football statistics through interactive visualizations.

## 📈 Dashboard Insights

The dashboard includes the following visualizations:

| Visualization | Description |
|---|---|
| 🏆 Champions vs Goals | Compares winning teams based on goals scored. |
| 🥈 Runners-up vs Goals | Analyzes goals scored by runner-up teams. |
| 🥉 Third Place | Highlights third-place teams. |
| ⚽ Goals Scored | Displays the total goals scored. |
| 🏟️ Matches Played | Shows the total matches played. |
| 👥 Teams Participation | Analyzes participating teams across World Cup years. |
| 🥇 Champions Distribution | Donut chart showing championship distribution among teams. |
| 📅 Year Filter | Allows analysis of different World Cup editions. |
